# ✨ Overview

Dynamic Resume Builder is a modern frontend application designed to help users create professional resumes through an intuitive and interactive interface.

The application provides real-time preview functionality, dynamic form management, and local storage persistence, allowing users to seamlessly build and edit resumes without losing their progress.

Built using core web technologies, this project demonstrates practical frontend development concepts including DOM manipulation, event handling, form validation, and responsive UI design.

---

# 🚀 Features

## 📝 Real-Time Resume Preview

Instantly visualize resume changes while editing user information.

---

## ➕ Dynamic Skills & Experience Management

Add multiple skills and work experiences dynamically using JavaScript DOM manipulation.

---

## 💾 Local Storage Persistence

Resume data is automatically saved using `localStorage`, allowing users to continue editing later.

---

## ✅ Form Validation

Prevents empty required fields and ensures proper data entry.

---

## 🎨 Modern Responsive UI

Glassmorphism-inspired modern interface optimized for desktop and mobile devices.
