# Dynamic Resume Builder

A modern and responsive Dynamic Resume Builder created using HTML, CSS, and JavaScript. This project allows users to create professional resumes with live preview functionality, dynamically add skills and experiences, validate form inputs, and save data using localStorage.

---

## Features

- Real-time resume preview
- Dynamic skill addition
- Dynamic experience addition
- Form validation
- Data persistence using localStorage
- Responsive modern UI
- Professional resume layout
- Interactive user experience

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation & localStorage)

## How It Works

### User Inputs

Users can enter:

* Name
* Email
* Phone Number
* Professional Summary
* Skills
* Experience

---

### Dynamic Features

#### Skills

Users can:

* Add skills dynamically
* Display skills instantly in resume preview

#### Experience

Users can:

* Add multiple work experiences
* Display them instantly in the preview section

---

### Live Preview

The resume preview updates automatically whenever the user edits the form.

---

### localStorage Support

The application stores user data in localStorage so the resume remains saved even after refreshing or reopening the browser.
